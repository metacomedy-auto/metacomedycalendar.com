# metacomedycalendar.com

메타코미디 캘린더의 소개 페이지와 개인정보처리방침. GitHub Pages로 `https://metacomedycalendar.com`에 올라가요.
구글 OAuth 동의 화면(로그인 프로젝트 `metacomedy-calendar`)의 '앱 홈페이지'·'개인정보처리방침' 링크가 여기를 가리킵니다.

- `index.html` 홈페이지 · `privacy.html` 개인정보처리방침 · `style.css` · `assets/`
- `CNAME` 사용자 정의 도메인 · `.nojekyll` Jekyll 처리 안 함
- 고치면 `main`에 푸시하면 몇 분 안에 반영돼요. 방침을 고칠 땐 본문의 시행일도 함께.
